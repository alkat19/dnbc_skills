Documentation and guidance
All variables start with an A and contain three chiffers (e.g. A000). The answer categories are listed
starting with 1.

In most questions, the "undefined" variable has been given code 9, and the "irrelevant" variables
has been given the code 10. 11 code for "irrelevant in this version, as the question was not asked".
However, in questions with 10 or more answer categories these variables have been given code
99, 100 and 101. In continuing variables, which can include the value 99, the codes 999 and 1000
are used. In date variables code 99999999 and 100000000 are used.

If AINTROB = 2 or 3, the values for irrelevant are given in all the following questions.

If a question is dependent on a previous answer a note is written in Concolas (e.g. A001,
Dependent on A000) above the question. Likewise it is specified which question the respondent
jumps to if the following questions depend on the answer of the question concerned (e.g. → A002).

Variable names ending with a letter (e.g. A002A) is a sub question of the previous question where
it does not make sense to assign the question a new name.
